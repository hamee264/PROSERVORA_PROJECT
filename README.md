# 🇳🇬 NaijaFix

NaijaFix is a service marketplace platform designed to connect customers with trusted service providers across Nigeria.

Customers can discover services, create service requests, communicate with providers, hire professionals, and make payments through the platform. Service providers can create profiles, list their services, receive opportunities, manage jobs, and track their earnings.

## 🚀 Features

### Customers
- Create an account and manage their profile
- Browse available services
- Search and filter service providers
- View provider profiles and services
- Create service requests
- Receive and review provider offers
- Communicate with service providers
- Hire providers
- Make payments
- Track active and completed jobs
- Review and rate providers

### Service Providers
- Create and manage a professional profile
- Add and manage services
- Set provider status:
  - Online
  - Offline
- Toggle availability for work
- View available job opportunities
- Respond to customer requests
- Manage active jobs
- Communicate with customers
- Track completed jobs and earnings
- Receive payments

### Platform
- Secure authentication and authorization
- Role-based access
- Service marketplace
- Customer/provider profiles
- Job management
- Messaging
- Notifications
- Payments
- Reviews and ratings
- Secure handling of user and payment data
